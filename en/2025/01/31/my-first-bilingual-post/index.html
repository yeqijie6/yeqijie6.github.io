My first bilingual article

Created2025-01-31|Updated2025-01-31|blog

Welcome to my bilingual blog! This is an example article demonstrating how to implement the Chinese English switching function in Hexo.
##What is i18n (internationalization)?
I18n is an abbreviation for Internationalization (starting with the letter i, ending with the letter n, and consisting of 18 letters in the middle). It is a practice of software design and development used to enable applications to support multiple languages and regions.
##Hexo’s i18n Implementation
Hexo supports multiple languages through the following configuration:

      • Configuration file settings * * (xcOD_SLOCK_1_):
        -_xcOD_SLOCK2_2- Specify the supported languages
        -xcOD_SLOCK_3         - Format the language directory
      • Document organization * *:
        -Chinese article: xCOD_SLOCK_4_
        -English article: xCOD_SLOCK_5_
        -File name remains consistent, Hexo automatically recognizes language
  3. Front Matter Configuration:
    -Add xcOD_SLOCK_6 to indicate the language of the article
    ##How to create bilingual articles
    ###Step 1: Create a directory

###Step 2: Create a Markdown file with the same name
The file name must be the same, just placed in different language directories.
###Step 3: Write the content
Add the tag 2COD_SLOCK_7_ in Front Matter to indicate the language of the article.
##View the English version
Click the language switch button on the navigation bar or access the corresponding English URL to see the English version of this article.

**Tip * *: Ensure that the Chinese and English versions of the article use the same xcOD_SLOCK_8_ field so that Hexo can establish the association correctly.
